# Student Grade Calculator

A beginner-friendly Python project created for the Codomax AI & ML Internship.

## Features
- Gets the student's name.
- Accepts marks for multiple subjects.
- Checks that each mark is between 0 and 100.
- Calculates total and average marks.
- Assigns a grade based on the average.
- Displays the final result.

## Python concepts used
- Variables and data types
- Lists
- `for` and `while` loops
- `if`, `elif` and `else` conditions
- Functions
- User input and output

## How to run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run:

```bash
python student_grade_calculator.py
```

## Grade scale
| Average | Grade |
|---|---|
| 90–100 | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 50–59.99 | D |
| Below 50 | F |

This is a basic practice project. The grade scale can be changed according to an institution's rules.
